## 2. 全局架构与导航（彻底告别笨重 Material 底栏）
1. **底部 3 标签悬浮胶囊导航栏（`FloatingPillTabBar`）**：
   - 仅保留原版 3 个主标签：**订阅** / **规则** / **导出**。
   - 居中悬浮在页面内容上方（`navigationBarsPadding()` + `10.dp` 底部留白），圆角 `32.dp`，高度 `60.dp`，宽约 `248.dp`，浅色模式 `Color.White.copy(alpha = 0.93f)` / 深色模式 `Color(0xFF182030).copy(alpha = 0.93f)`，带 `0.75.dp` 柔和边框和 `14.dp` 环境阴影。
   - 选中项背后使用**平滑弹簧滑动的胶囊指示器**（`animateDpAsState` + `spring(dampingRatio = 0.88f, stiffness = 420f)`），浅色填充 `#EBF0FA` / 深色 `#25324B`，图标/文字切换为 Tower 蓝色并伴随 `0.92f -> 1f` 微缩放与轻触觉反馈（`HapticFeedbackType.TextHandleMove`）。
   - 页面滚动列表底部留足 `108.dp`（导出页带悬浮操作栏时留 `176.dp`）的 `contentPadding.bottom`，让内容优雅地滑过悬浮栏下方。
2. **设置入口变为独立弹窗（`SettingsSheet`）**：
   - 与原版 `iphone-3.jpg` / `iphone-5.jpg` 一致，顶部右上角悬浮胶囊按钮「设置」（在导出页显示；订阅页/规则页顶部栏也可以简洁提供或通过导出页进入）打开全屏圆角 Modal 弹窗，顶部右上角带悬浮胶囊「完成」按钮。
3. **非阻塞底部刷新状态胶囊**：
   - 批量刷新订阅时，在悬浮胶囊导航栏上方浮现紧凑状态胶囊（旋转指示器 +「正在刷新订阅…」+ 取消按钮），从底部平滑滑入（`spring(dampingRatio = 1f, stiffness = 380f)`），页面保持完全可交互。
4. **统一 `TowerToastHost`**：
   - 紧贴内容宽度的顶部悬浮胶囊（`17.dp` 圆角、`29.dp` 圆形渐变图标徽标、微妙染色边框与阴影），入场缩放 `0.96f -> 1f` + 透明度过渡（`TowerMotion.SurfaceSpring`）。

## 3. 动效与微交互规范（`TowerMotion` & 公共组件）
1. **无回弹克制弹簧与按压反馈**：
   - `Modifier.towerPressScale()`：按下 `100ms easeOut` 缩至 `0.97f`、透明 `0.86f`；松开 `160ms easeOut` 恢复 `1f`。所有主按钮、客户端图标、地图测速胶囊、次级卡片按钮必须接入。
   - `TowerSelectionCheckmark`：严格复刻原版 `CheckmarkToggleStyle`（`25.dp` 圆形、外层 `44.dp` 点击热区）：未选中 `1.5.dp` 柔和灰圈；选中平滑填充 Tower 蓝 + 白色粗勾号 `0.92f -> 1f` 缩放淡入 + 触觉反馈。用于订阅卡片和规则方案卡片，替代笨重的 Material Switch。
   - `TowerSegmentedControl`：原版 iOS 分段控件（`完整配置` | `仅节点`），圆角胶囊轨道 + **平滑弹簧滑动的纯白阴影滑块**。
   - `TowerNumericText`：数字变化时垂直平滑滚动 + 淡变（用于指标计数与延迟毫秒数）。
   - `TowerLatencyBadge`：固定最小宽度 `58.dp` 右对齐槽位（`animation-plans/003`），批量测速期间行内节点名宽度绝不抖动！状态在转圈 / 延迟毫秒 / `—` 之间原地淡变。
   - `TowerIosSwitch`：精致的 `48×28.dp` 紧凑胶囊开关（浅灰/蓝轨道 + 纯白带微阴影圆形滑块弹簧位移动画），用于设置项和策略组启停。
   - `TowerFloatingPillButton` / `TowerFloatingCircleButton`：复刻 `iphone-1/2/3.jpg` 与 Mobbin Aave 的顶部悬浮胶囊（`管理`、`设置`、`导入规则`、`完成`）和圆形图标按钮（`+`）。

## 4. 四大核心页面精修要求

### 4.1 订阅页（`SubscriptionsScreen.kt` + `WorldDotMapCanvas.kt` + `SubscriptionCard.kt`）
- **顶部栏**：左悬浮胶囊「管理」（打开节点搜索/筛选/批量管理面板），右悬浮圆形「+」按钮；下方 `32.sp` Bold 大标题「我的订阅」。
- **一体化统计 + 点阵世界地图卡片（严格对照 `iphone-1.jpg`）**：
  - 同一张 `22.dp` 圆角纯白/深色卡片内分为上下两区，中间 `0.5.dp` 细分隔线：
    - **上区**：4 列无边框指标（`🌐 节点`、`🌍 地区`、`📡 订阅 x/y`、`📋 自有节点`），带彩色小图标 + `TowerNumericText`。
    - **下区**：贴边渲染的 `WorldDotMapCanvas`（220×149 网格，无联网地图）：
      - 陆地点：细腻小圆点（浅色 `#DDE2EC` / 深色 `#273145`）。
      - 覆盖国家点：严格使用原版 `MapLatencyBand` 色值（未测速灰蓝 `#7A96B0`、≤100ms 翠绿 `#0FA67D`、≤200ms 湖蓝 `#3387D6`、≤350ms 琥珀 `#D49424`、>350ms 珊瑚红 `#E35C3D`、不可达玫红 `#AD477A`）；选中国家同色系加深 + 点径由 `0.72` 增至 `0.90`。
      - **地图内嵌国家名称标签胶囊**：直接悬浮在有节点覆盖的国家位置上（如「美国」「德国」「日本」「香港」「澳大利亚」），带轻量防重叠算法、白底细边圆角标签、保持中性深色文字（选中国家标签加粗微抬升）。
      - **右上角悬浮「测速」胶囊**：玻璃白底微阴影，图标+文字在「测速」与「x/n · 停止」之间平滑宽幅过渡，批量测速完成触发成功触感。
      - **左下角延迟渐变图例**：有测速结果时淡入 `100 ━━━ 350 ms`（翠绿→湖蓝→琥珀→珊瑚红渐变细条）。
      - **平滑手势与居中动画**：支持双指缩放、拖动平移、双击或点悬浮「复原」胶囊回中；点击任意覆盖国家轮廓时，使用 `Animatable` 临界阻尼弹簧平滑缩放至 `1.8f` 并居中到该国，同时在地图卡片下方优雅展开该地区节点列表卡片！
- **订阅卡片（严格对照 `iphone-1.jpg`）**：
  - 首行：`40.dp` 淡蓝圆角底（`12.dp`）+ 蓝色信号图标 | 粗体订阅名 + 灰色域名 | `0°↔180°` 旋转箭头 | `TowerSelectionCheckmark` 蓝色圆勾。
  - 流量区：`◔ 剩余 xxx GB`（左）+ `总流量 xxx GB`（右）+ **超细 `3.5.dp` 翠绿平滑进度条**。
  - 底栏（细分隔线下）：`13 个节点 · 160 天到期`（左）+ `🕒 6分钟前` + 蓝色刷新图标（刷新时平滑旋转）+ 蓝色分享图标（右）。
  - 展开节点列表：仅使用平滑透明度 + 高度过渡（**严禁顶部滑入**，CLAUDE.md #7），不提供「显示更多节点」；国旗直接显示 Emoji 不加圆形底（CLAUDE.md #20）；每行轻点打开 `NodeDetailSheet`。

### 4.2 规则页（`RulesScreen.kt` + `RuleCustomizationSheet.kt`，对照 `iphone-2.jpg`）
- 顶部大标题「分流规则」+ 右上角悬浮胶囊「导入规则」。
- 主列表展示「本机规则 · 安装后离线可用」（ACL4SSR 默认 / 全分组 / 精简）与「已导入」规则方案卡片：
  - 每张方案卡片右侧为 `TowerSelectionCheckmark` 选为当前方案；轻点卡片进入全屏圆角 **`RuleCustomizationSheet`**（完全复刻 `iphone-2.jpg`！），同时当前选中的方案卡片下方展示快捷入口「查看与定制策略组（N 组）>」。
- **`RuleCustomizationSheet`（严格复刻 `iphone-2.jpg`）**：
  - 顶栏：左侧悬浮胶囊（规则库/新建）、居中「规则定制」、右侧悬浮胶囊「完成」。
  - 胶囊搜索框：「🔍 搜索规则：如 YouTube OpenAI」，实时过滤策略组或跳转规则库搜索。
  - **单列表统一分组白卡片**（CLAUDE.md #26）：全部策略组在卡片内以细腻缩进分隔线排列——左：Emoji + 名称 + 淡蓝铅笔 `✎`；右：蓝色当前目标（如 `自动选择 >`、`节点选择 >`、`DIRECT >`、`REJECT >`）+ 灰色三横杠拖拽手柄 `≡`。
  - **真实跟手拖拽排序**：长按或按住右侧 `≡` 手柄即可上下拖移，拖动行微放大 `1.02f` + 抬升阴影 + 跨槽位轻触感，松手后调用 `reorderRuleGroups()`，若有匹配冲突立刻弹出「匹配结果会改变」弹窗并提供一键「撤销」。
  - 下方紧接「我的规则集」（`N 个` + 蓝色「新建规则集」入口）与「策略组 Emoji 开关」。

### 4.3 导出页（`ExportScreen.kt` + `ConfigurationViewerSheet.kt`，对照 `iphone-3.jpg` & `iphone-4.jpg`）
- 顶栏右上角悬浮胶囊「设置」（打开 `SettingsSheet`），下方大标题「生成与导出」。
- **目标客户端横向选择器（严格复刻 `iphone-3.jpg` + `ExportView.swift`）**：
  - 标题「目标客户端」+ 右侧蓝色「客户端筛选 >」。
  - 横向滚动裸图标列表（Android 原生客户端排最前，**「局域网共享」作为蓝青渐变路由图标同排展示**！）：每个项仅由 `58.dp` 圆角图标（`13.dp` 圆角、微阴影、细描边，**绝不包厚边框大卡片**）+ 下方居中名称组成；选中项右下角弹出 `20.dp` 蓝底白勾圆形角标（带纯白外环，`scale 0.6->1` 弹簧入场）！
- **主内容区**：
  - 当选中「局域网共享」时，平滑淡变显示一体化「局域网共享」卡片（开关、局域网地址复制、格式选择器、Token 轮换、大号扫码二维码、Android 本地网络权限提示），并淡出底部导入栏。
  - 当选中客户端时，展示严格对照 `iphone-3.jpg` 的**一体化状态与选项卡片**：
    - 顶行：「转换已就绪」（冷生成超过 200ms 才淡变为「正在转换…」）+ 右侧绿色 `Verified` 徽章（不换成转圈防闪烁）。
    - `TowerSegmentedControl`：`完整配置` | `仅节点`（按客户端能力自动显示）。
    - 卡片内嵌分隔列表行：
      - `规则方案` → 当前方案名 `>`（点击切到规则页）
      - `协议筛选` → `全部协议` / `已排除 N 项 >`（弹出 `ProtocolFilterSheet`）
      - `高级选项` → `>`（展开 DNS 保护 / 优先规则集 / 代理集合）
    - 摘要行：`28 兼容节点   3,529 本地规则`
    - `兼容性提示 N >`（拦截/REJECT 跳过提示置顶醒目高亮）
    - `配置预览 塔台.yaml >`（打开对照 `iphone-4.jpg` 的全屏语法高亮预览编辑器）
- **底部悬浮主操作栏（位于悬浮 3 标签栏正上方，带顶部透明→背景渐变遮罩！）**：
  - 主按钮：鲜明蓝色 `52.dp` 圆角按钮（`16.dp` 圆角），内置当前客户端 `24.dp` 小图标 + `一键导出到 {Client}`（QuanX 完整配置模式下严格为「分享配置文件」，遵循 CLAUDE.md #4！）。
  - 右侧配 `52.dp` 柔和灰底圆角方形 `…` 按钮，弹出菜单：分享配置文件 / 复制配置文本 / 预览与编辑。

### 4.4 设置页弹窗（`SettingsScreen.kt`，对照 `iphone-5.jpg`）
- 以全屏圆角弹窗呈现（同时兼容作为独立页），顶栏居中「设置」+ 右上悬浮胶囊「完成」。
- 严格采用分组白卡片 + **左侧 `32.dp` 彩色圆角图标徽标** + 缩进分隔线 + `TowerIosSwitch`：
  - **节点与配置**（右标「默认保持原始订阅」）：蓝标「节点附加订阅名称」、橙标「过滤订阅节点信息」、紫标「优先使用规则集」、绿标「代理集合」、青标「配置名称」。
  - **连接**：靛蓝地球「Tailscale 内网 >」（Auth Key 仅存 Android KeyStore，不进导出快照）。
  - **外观与测速**：Perplexity 风格 3 格外观卡片（浅色 / 深色 / 跟随系统）、DNS 保护模式、测速模式。
  - **备份与数据**：SAF 导出/导入 JSON、重看欢迎引导、双重确认重置全部数据、版本号 `1.0.34 (84)`。
